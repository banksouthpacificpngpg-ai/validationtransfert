# BSP YAL Bank — Multi-Step PNG Transfer Validation Demo

Fictional training/demo project.

Flow:
1. Client information
2. Transfer details
3. Sender & beneficiary
4. Compliance & declarations
5. Review & confirmation
6. EmailJS submission

The project includes 22 PNG provincial-level units, including National Capital District and Bougainville.

Configure EmailJS in js/config.js.

Security: never collect passwords, PINs, OTPs, CVVs or online-banking credentials. A real banking service requires secure backend authentication, authorization, server-side validation, audit logs, encryption, fraud controls and regulatory review.
